# 发布清单：让用户从 GitHub「下载即用」

普通用户**不要**下载源码 zip，也**不要**自己装 Python。  
他们只需要从 **Releases** 页面下载已经打包好的程序。

---

## 你需要做的事（一次性 + 每次发新版）

### 第一步：把最新代码推到 GitHub

```powershell
cd "c:\Users\1\webtest script"
git add .
git commit -m "prepare release v3.0.0"
git push origin main
```

### 第二步：打版本标签（触发自动打包，推荐）

仓库里已配置 `.github/workflows/release.yml`，推送 `v*` 标签后会自动：

1. 在云端编译 Windows 的 `SplitScreenSnap.exe`
2. 在云端编译 macOS 的 `分屏截屏助手.app` 并打成 zip
3. 自动创建 **GitHub Release** 并附上这两个文件

```powershell
git tag v3.0.0
git push origin v3.0.0
```

等 5~15 分钟，打开：  
https://github.com/Sumluvv/Miao-Screenshot/releases  

应能看到 **v3.0.0**，附件里有：

| 文件 | 给谁用 |
|------|--------|
| `SplitScreenSnap.exe` | Windows 用户，双击即用 |
| `SplitScreenSnap-mac.zip` | Mac 用户，解压后打开 `.app` |

### 方式 B：本机手动打包再上传（不用 Actions 时）

**Windows：**

```powershell
.\scripts\build_windows.ps1
```

得到 `dist\SplitScreenSnap.exe`，在 GitHub 网页：

1. 仓库 → **Releases** → **Draft a new release**
2. Tag：`v3.0.0`，标题：`分屏截屏助手 v3.0.0`
3. 把 `SplitScreenSnap.exe` 拖进 **Attach binaries**
4. 点 **Publish release**

**macOS：** 必须在 Mac 上运行 `./scripts/build_macos.sh`，再上传 zip。

---

## 用户下载后怎么用（写进 Release 说明即可）

### Windows

1. 打开 [Releases](https://github.com/Sumluvv/Miao-Screenshot/releases)  
2. 下载 **SplitScreenSnap.exe**（不要下载 Source code）  
3. 双击运行（若 SmartScreen 提示，点「更多信息」→「仍要运行」）  
4. 无需安装 Python  

### macOS

1. 下载 **SplitScreenSnap-mac.zip** 并解压  
2. 将 **分屏截屏助手.app** 拖入「应用程序」  
3. 首次运行若被拦截：系统设置 → 隐私与安全性 → 仍要打开  
4. 若要用 F8：系统设置 → 隐私与安全性 → 辅助功能 → 允许本应用

## 常见问题

**Q：用户下了 Source code zip 打不开？**  
A：那是源码，不是程序。请在 Release 里下载 `SplitScreenSnap.exe`。

**Q：Actions 没跑起来？**  
A：仓库 Settings → Actions → General → 允许 Actions；再重新 `git push origin v3.0.0`。

**Q：只想发 Windows，不发 Mac？**  
A：可只上传 exe；或删掉 workflow 里 `build-macos` 任务。
