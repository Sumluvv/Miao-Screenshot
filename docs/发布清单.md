# 发布清单：让普通用户可以直接安装

普通用户不需要安装 Python，也不需要下载 Source code。每次发布时，请确保 Releases 页面至少有 Windows 安装包。

## 推荐发布附件

| 文件 | 用途 |
| --- | --- |
| `SplitScreenSnap-Setup.exe` | Windows 安装版，推荐普通用户下载 |
| `SplitScreenSnap.exe` | Windows 免安装版，适合临时运行 |
| `SplitScreenSnap-mac.zip` | macOS 版本，解压后打开 `.app` |

## 自动发布流程

仓库已配置 `.github/workflows/release.yml`。推送 `v*` 标签后会自动：

1. 编译 Windows 免安装版 `SplitScreenSnap.exe`
2. 使用 Inno Setup 生成 Windows 安装版 `SplitScreenSnap-Setup.exe`
3. 编译 macOS `.app` 并压缩为 `SplitScreenSnap-mac.zip`
4. 创建 GitHub Release 并上传附件

```powershell
cd "C:\Users\1\webtest script"
git add .
git commit -m "release: prepare v3.0.7"
git push origin main

git tag v3.0.7
git push origin v3.0.7
```

等待 5 到 15 分钟后，打开：

https://github.com/Sumluvv/Miao-Screenshot/releases

## 本机手动打包

Windows：

```powershell
.\scripts\build_windows.ps1
```

输出：

- `dist\SplitScreenSnap.exe`
- `dist\SplitScreenSnap-Setup.exe`，需要本机安装 Inno Setup

macOS：

```bash
chmod +x scripts/build_macos.sh
./scripts/build_macos.sh
```

输出：`dist/分屏截屏助手.app`，发布前建议压缩成 zip。

## 发布前检查

- [ ] `python -m py_compile main.py app_meta.py ui_theme.py` 通过
- [ ] Windows 安装版能安装、启动、卸载
- [ ] Windows 免安装版能直接双击打开
- [ ] Release 附件包含 `SplitScreenSnap-Setup.exe`
- [ ] README 顶部指向 Releases 下载页
- [ ] 没有把 `dist/`、`build/`、`config.json`、`screenshots/` 提交进仓库

## 给用户的下载说明

Windows 用户优先下载 `SplitScreenSnap-Setup.exe`。如果不想安装，再下载 `SplitScreenSnap.exe`。

如果用户下载的是 `Source code.zip`，那不是程序本体，需要重新引导到 Releases 附件区。
